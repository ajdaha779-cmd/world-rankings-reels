РЕЙТИНГИ СТРАН — как это работает
==================================

Что делает компьютер сам
------------------------
Каждую субботу в 09:00 (после включения автозапуска, см. ниже) Mac делает пачку:
  • 14 роликов на реальных данных Всемирного банка — 2 в день на неделю вперёд;
  • названия, описания и хештеги на английском;
  • расписание публикаций (по Баку).
Если Mac в это время спал — пачка соберётся, когда он проснётся.
Если Mac был выключен — дважды кликни «Сделать-пачку.command».
Когда готово — придёт уведомление «Рейтинги: Готово».

Пачка лежит в:  к-публикации/<дата>/
  01_....mp4 … 14_....mp4   — ролики
  РАСПИСАНИЕ.txt            — когда выкладывать каждый ролик + готовые тексты
  metadata.json             — то же самое для программ (пригодится для автозагрузки)

Включить / выключить автозапуск
-------------------------------
  автозапуск/Включить.command   — двойной клик, один раз
  автозапуск/Выключить.command  — если надо остановить
(Если macOS не даёт открыть: правый клик → «Открыть» → «Открыть».)


ЧТО ДЕЛАЕШЬ ТЫ — раз в неделю, ~20 минут (суббота/воскресенье)
==============================================================
Открой РАСПИСАНИЕ.txt и иди по списку. Для каждого ролика:

YouTube (с компьютера, studio.youtube.com)
  1. «Создать» → «Загрузить видео» → выбери ролик.
  2. Название и описание — скопируй из РАСПИСАНИЕ.txt.
  3. «Нет, это видео не для детей».
  4. Шаг «Доступ» → «Запланировать» → дата и время из расписания (время по Баку).
  Можно выбрать сразу несколько файлов — YouTube загрузит их пачкой, потом проставишь даты.

TikTok (с компьютера, tiktok.com → «Загрузить» / TikTok Studio)
  1. Выбери ролик, вставь подпись из расписания.
  2. «Запланировать» → дата и время. TikTok позволяет планировать примерно на 10 дней вперёд.

Instagram (приложение Instagram или Meta Business Suite)
  1. Нужен профессиональный аккаунт (Настройки → Тип аккаунта → «Автор» или «Бизнес»).
  2. Новый Reels → подпись из расписания → «Дополнительные настройки» → «Запланировать».

После этого площадки сами публикуют по графику — компьютер может быть выключен.


ПЕРВЫЙ ЗАПУСК — один раз
========================
1. Создай каналы с одним названием везде, например «World in Numbers»:
   YouTube, TikTok, Instagram. Язык/описание — английский:
   «Countries compared daily 🌍 Real data from the World Bank».
2. В YouTube: Настройки → Канал → страна проживания — Азербайджан
   (нужна для партнёрской программы; проверь, что она там доступна —
   YouTube Studio → «Монетизация» покажет условия).
3. Закрепи под первыми роликами комментарий:
   «What should we compare next? 👇»


ДАЛЬШЕ: полная автозагрузка в YouTube (без твоих 20 минут)
==========================================================
Через API YouTube новые приложения могут выкладывать видео только как «приватные»,
пока Google не проверит приложение (бесплатная проверка, обычно несколько недель).
План:
  1. Google Cloud Console → новый проект → включить «YouTube Data API v3».
  2. Экран согласия OAuth + ключ типа «Desktop app» → скачать client_secret.json
     и положить в папку проекта.
  3. Подать заявку на YouTube API Audit (форма «YouTube API Services – Audit and Quota Extension»).
  4. После одобрения скрипт будет сам загружать ролики с расписанием.
Шаги 1–2 можно сделать вместе с Claude — он подскажет каждый клик.


ВАЖНО
=====
• Темы не повторяются: использованные записываются в data/used.json.
  Сейчас ~200 комбинаций «тема × регион» — примерно на 3 месяца по 2 ролика в день.
  Новые темы добавляются в catalog.py (Claude сделает).
• Данные обновляются с сайта Всемирного банка раз в неделю; источник и год видны в кадре.
• Код: engine.py (графика/звук), render.py (ролик), catalog.py (темы), make_batch.py (пачка).
